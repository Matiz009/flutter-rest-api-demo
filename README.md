# Flutter REST API Demo

A Flutter app that fetches data from REST APIs and shows it on different screens.

## Features

- Posts, comments and users from [JSONPlaceholder](https://jsonplaceholder.typicode.com)
- Navigation drawer and a splash screen
- Light/dark theme toggle (Provider)
- Contact-us form

## Tech stack

Flutter · Dart · http · Provider

## Getting started

```bash
flutter pub get
flutter run
```

## Project structure

```
lib/  main, splash_screen, my_home_page, home_body, posts/post, comments/comment, users/user,
      contact_us_form, navigation_widget_drawer, theme_provider, change_theme_button_widget
```
